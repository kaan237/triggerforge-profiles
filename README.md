# TriggerForge community profiles

Profiles for [TriggerForge](https://github.com/kaan237/triggerforge). In the app: Profiles → Community.

The app only accepts this catalog when `index.json.sig` matches, so entries become visible after a maintainer reviews and signs them.

## Share a profile

1. In the app, open your profile and choose **Export for sharing**. Actions that start programs are removed.
2. Add the file to `profiles/` and the copied entry to `index.json`. Fill in your name, tags and both descriptions.
3. Open a pull request.

Profiles that start programs are rejected.

# TriggerForge topluluk profilleri

Uygulamada: Profiller → Topluluk. Uygulama kataloğu yalnız `index.json.sig` imzası tutarsa kabul eder; yeni girdiler inceleme ve imzadan sonra görünür.

1. Uygulamada profilinizi açıp **Paylaşım için dışa aktar**'ı seçin. Program çalıştıran eylemler silinir.
2. Dosyayı `profiles/` klasörüne, kopyalanan girdiyi `index.json` dosyasına ekleyin. Adınızı, etiketleri ve iki dilde açıklamayı doldurun.
3. Çekme isteği (pull request) açın.
